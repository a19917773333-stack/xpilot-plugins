# 维护模式开关

车辆动作（CAN）插件。打开“发送一次维护模式命令”时，只向 CAN2 发送一帧：

先在分类页打开“维护模式开关”母开关，再进入插件页点击“发送一次维护模式命令”。命令发送完成后会自动清零。

- CAN ID: `0x339`
- Bus: CAN2（Panda bus `1`）
- Data: `00 00 00 00 00 80 00 00`

命令不会自动重复发送，关闭开关也不会发送退出帧或任何其他帧。点击脉冲只在 1 秒内有效，发送后参数自动清零。

Panda 运行时规则仅允许上述 TX 地址、总线、长度和固定数据；RX 只把 `0x3C2` 用作车辆在线证明。规则要求 Tesla 车辆总线模式、CAN2 有近期 `0x3C2` 帧，并限制每秒最多一帧。
